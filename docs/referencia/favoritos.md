# favoritos

Funções pré-parametrizadas de outros módulos, para as consultas mais comuns: inflação, Selic, PIB,
câmbio, salário mínimo, bandeiras e brasões dos estados, entre outras.

Todas são importadas direto no pacote, então `dab.selic()` e `favoritos.selic()` são a mesma função:

```python
import DadosAbertosBrasil as dab

dab.selic()
```
